How to Pick the Right Algorithm

Is the input sorted? ├─ YES → Binary Search / Two Pointers └─ NO → Continue ↓ Is it about subarray / substring? ├─ Fixed window → Sliding Window ├─ Variable window → Sliding Window + HashSet/Map └─ Subsequence → DP Is it a graph / tree? ├─ Shortest path (unweighted) → BFS ├─ Shortest path (weighted) → Dijkstra / Bellman-Ford ├─ All paths / combinations → DFS + Backtracking └─ Topological order → BFS (Kahn's) / DFS Is it an optimisation (min/max/count)? ├─ Overlapping subproblems → Dynamic Programming ├─ Greedy choice works → Greedy └─ Try all possibilities → Backtracking Do you need the k-th largest / smallest? └─ Heap (Min or Max) Do you need prefix lookups / autocomplete? └─ Trie Is it about intervals (merge / schedule)? └─ Sort by start → Sweep / Greedy Is there a monotonic property (next greater, stock span)? └─ Monotonic Stack / Queue

Sliding Window

O(n)
📐
Fixed-Size Window
Window size k stays constant
arr = [1, 3, -1, -3, 5, 3, 6, 7] k=3 [1 3 -1] -3 5 3 6 7 sum=3 1 [3 -1 -3] 5 3 6 7 sum=-1 1 3 [-1 -3 5] 3 6 7 sum=1 ← slide right, add right, remove left →
max sum subarray size k sliding window maximum average of subarrays
Skeleton:
int sum = 0, max = 0; for (int i = 0; i < n; i++) { sum += arr[i]; if (i >= k) sum -= arr[i - k]; if (i >= k-1) max = Math.max(max, sum); }
Time O(n) Space O(1)
🔀
Variable-Size Window
Expand right, shrink left on violation
s = "abcabcbb" find longest no-repeat left right ↓ ↓ [a b c] a b c b b window={a,b,c} len=3 [b c a] b c b b duplicate 'a' → shrink left
longest substring without repeat minimum window substring at most k distinct
int left = 0, max = 0; Set<Char> seen = new HashSet<>(); for (int right = 0; right < n; right++) { while (seen.contains(s.charAt(right))) seen.remove(s.charAt(left++)); seen.add(s.charAt(right)); max = Math.max(max, right - left + 1); }
Time O(n) Space O(k)

Binary Search

O(log n)
🎯
Classic Binary Search
Find exact target in sorted array
arr = [1, 3, 5, 7, 9, 11] target=7 lo=0 hi=5 mid=2 (arr[2]=5 < 7) → lo=3 lo=3 hi=5 mid=4 (arr[4]=9 > 7) → hi=3 lo=3 hi=3 mid=3 (arr[3]=7 ✓) FOUND
search in sorted array find position rotated sorted array
int lo = 0, hi = n - 1; while (lo <= hi) { int mid = lo + (hi - lo) / 2; if (arr[mid] == target) return mid; else if (arr[mid] < target) lo = mid + 1; else hi = mid - 1; }
Time O(log n) Space O(1)
📊
Binary Search on Answer
Search on the result space, not the array
"What is the minimum capacity so that we can ship all packages in D days?" Instead of trying every capacity: → Binary search capacity [max(w), sum(w)] → For each candidate, check if feasible O(n) → Total: O(n log(sum))
minimum / maximum capacity split array largest sum koko eating bananas median of two arrays
int lo = min, hi = max; while (lo < hi) { int mid = lo + (hi - lo) / 2; if (feasible(mid)) hi = mid; else lo = mid + 1; } return lo;
Time O(n log m) Space O(1)

Breadth-First Search (BFS)

O(V+E)
🗺️
BFS — Shortest Path
Level-by-level exploration in a graph/grid
Graph: A─B─C─D find shortest A→D └─E─┘ Level 0: [A] Level 1: [B, E] ← neighbours of A Level 2: [C, D(via E)] ← neighbours of B,E Level 3: [D(via C)] First time D is reached = shortest path
shortest path unweighted minimum steps level-order traversal word ladder number of islands
Queue<Node> q = new LinkedList<>(); Set<Node> visited = new HashSet<>(); q.add(start); visited.add(start); while (!q.isEmpty()) { Node cur = q.poll(); for (Node nb : graph.get(cur)) { if (!visited.contains(nb)) { q.add(nb); visited.add(nb); } } }
Time O(V+E) Space O(V)

DFS / Backtracking

O(b^d)
🔙
Backtracking Template
Try → Recurse → Undo
Subsets of [1,2,3]: [] / \ [1] [] / \ / \ [1,2][1] [2] [] / [1,2,3]
all combinations all permutations all subsets maze / N-Queens word search
void backtrack(int start, List<Int> current) { result.add(new ArrayList<>(current)); // ← save for (int i = start; i < n; i++) { current.add(nums[i]); // choose backtrack(i + 1, current); // explore current.remove(current.size()-1); // undo } }

🗂️
DFS on Graph / Grid
Explore as deep as possible first
Grid BFS/DFS — 4-directional movement: [1 1 0] [1 0 0] Find all connected 1s (islands) [0 0 1] DFS from (0,0): visit (0,0)→(0,1)→(1,0) → mark visited separate island at (2,2)

Heap / Priority Queue

O(n log k)

Tree DFS Pattern
Post-order for bottom-up answers
Height / Diameter / Path Max Sum: → Ask LEFT subtree for its answer → Ask RIGHT subtree for its answer → Combine at current node → Return what PARENT needs This "return value" pattern handles almost all tree DP problems!
int dfs(TreeNode node) { if (node == null) return 0; int left = dfs(node.left); int right = dfs(node.right); // use left, right to update global answer ans = Math.max(ans, left + right + node.val); // return what parent needs return node.val + Math.max(left, right); }

If the problem says… Think… Complexity
"top k / k largest / k smallest" Heap of size k O(n log k)
"sorted array" + "find / search" Binary Search O(log n)
"subarray / substring" + "max/min length" Sliding Window O(n)
"all combinations / permutations" Backtracking / DFS O(2^n)
"shortest path" (unweighted graph) BFS O(V+E)
"shortest path" (weighted graph) Dijkstra / Bellman-Ford O((V+E)log V)
"minimum / maximum value" (optimisation) DP or Binary Search on Answer O(n²) or O(n log n)
"next greater / smaller element" Monotonic Stack O(n)
"prefix / autocomplete / word search" Trie O(m) per query
"cycle detection" in linked list / graph Fast & Slow Pointers / DFS + color O(n)
"merge intervals / meeting rooms" Sort by start + sweep O(n log n)
"course prerequisites / task order" Topological Sort (BFS / DFS) O(V+E)
"two sum" in sorted array Two Pointers (opposite ends) O(n)
"XOR / single number / missing number" Bit Manipulation O(n)
