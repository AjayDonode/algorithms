Sliding Window

O(n)
📐

Fixed-Size Window

Window of size k — add right, remove left
O(n) / O(1)
Use When
  • Window size k is given explicitly in the problem
  • Max/min/average of every subarray of size k
  • Sliding window maximum (use deque variant)
arr = [1, 3, -1, -3, 5, 3, 6, 7] k=3 [1 3 -1] → sum=3 1 [3 -1 -3] → sum=-1 1 3[-1 -3 5] → sum=1 1 3 -1[-3 5 3] → sum=5 1 3 -1 -3[5 3 6] → sum=14 ← MAX
Java Template
int sum = 0, max = 0; for (int i = 0; i < n; i++) { sum += arr[i]; if (i >= k) sum -= arr[i - k]; // remove element leaving window if (i >= k - 1) max = Math.max(max, sum); }
⚠Check i >= k-1 (not i >= k) before recording — window is full when index reaches k-1, not k.
LC 643 · Max Avg Subarray LC 239 · Sliding Window Max LC 438 · Anagrams in String
🔀

Variable-Size Window

Expand right; shrink left on constraint violation
O(n) / O(k)
Use When
  • Longest substring/subarray satisfying a constraint
  • Minimum window containing all required elements
  • Constraint checkable in O(1) with a map/set
s="abcabcbb" → longest no-repeat L=0 expand R: [a b c] valid, len=3 'a' repeats → shrink L [b c a] valid, len=3 'b' repeats → shrink L [c a b] valid, len=3 ← answer
Java Template
int left = 0, maxLen = 0; Map<Character,Integer> freq = new HashMap<>(); for (int right = 0; right < n; right++) { freq.merge(s.charAt(right), 1, Integer::sum); while (freq.get(s.charAt(right)) > 1) { // violation freq.merge(s.charAt(left), -1, Integer::sum); left++; } maxLen = Math.max(maxLen, right - left + 1); }
⚠Advance left with a while (not if) — multiple steps may be needed to restore the constraint validity.
LC 3 · Longest No-Repeat LC 76 · Min Window Substring LC 424 · Longest Repeating Char

Two Pointers

O(n)
↔️

Opposite Ends

L at 0, R at n-1 — converge toward center
O(n) / O(1)
Use When
  • Array is sorted (or can be sorted)
  • Find a pair / triplet summing to target
  • Check if string is a palindrome
arr = [-4, -1, 0, 3, 10] target = 9 L R [-4 -1 0 3 10] sum=6 < 9 → L++ L [-1 0 3 10] sum=9 = 9 → FOUND
Java Template
int left = 0, right = n - 1; while (left < right) { int sum = arr[left] + arr[right]; if (sum == target) { /* found */ break; } else if (sum < target) left++; else right--; }
⚠For 3Sum: sort first, fix one element, apply two-pointer on rest. Skip duplicates by advancing past equal values to avoid duplicate triplets.

Fast & Slow (Floyd's)

Slow=1 step · Fast=2 steps — detect cycles
O(n) / O(1)
Use When
  • Detect a cycle in a linked list
  • Find the middle of a linked list
  • Find cycle start node — phase 2 after meeting
1 → 2 → 3 → 4 → 5 → 3 (cycle!) Step Slow Fast 1 2 3 2 3 5 3 4 4 ← MEET → cycle exists! Phase 2: reset one to head, advance both 1 step → meet at start
Java Template
ListNode slow = head, fast = head; while (fast != null && fast.next != null) { slow = slow.next; fast = fast.next.next; if (slow == fast) return true; // cycle! } return false;
⚠Check fast != null && fast.next != null — both! Checking only fast.next != null causes NPE when fast itself is null.

Binary Search

O(log n)
🎯

Classic Binary Search

Halve search space each iteration
O(log n) / O(1)
Use When
  • Input is sorted (or rotated sorted)
  • Find first/last occurrence of value
  • Search in a monotonic answer space
arr=[1,3,5,7,9,11] target=9 lo=0 hi=5 → mid=2 → arr[2]=5 < 9 → lo=3 lo=3 hi=5 → mid=4 → arr[4]=9 = 9 → FOUND at 4 Rotated [4,5,6,7,0,1,2]: check which half is sorted → if left sorted & target in left range: go left, else right
Java Template
int lo = 0, hi = n - 1; while (lo <= hi) { int mid = lo + (hi - lo) / 2; // avoid overflow! if (arr[mid] == target) return mid; else if (arr[mid] < target) lo = mid + 1; else hi = mid - 1; }
⚠Use lo + (hi-lo)/2, not (lo+hi)/2 — overflow when lo+hi exceeds Integer.MAX_VALUE. Use lo <= hi for exact search; lo < hi for lower-bound search.

📊

Binary Search on Answer

Search the result space, not the input
O(n log m)
Use When
  • "Minimum X such that condition holds" (or max X)
  • Answer has a monotonic feasibility function
  • Brute force O(n²) but checking one answer is O(n)
"Min capacity to ship all packages in D days" Answer range: [max(weights), sum(weights)] BS on capacity c: feasible(c)? → try smaller: hi = mid not feasible? → need bigger: lo = mid + 1 Returns lo = smallest feasible capacity
Java Template
int lo = minPossible, hi = maxPossible; while (lo < hi) { // lo < hi for lower bound int mid = lo + (hi - lo) / 2; if (isFeasible(mid)) hi = mid; // shrink right else lo = mid + 1; // need bigger } return lo; // smallest feasible value
⚠For "minimum": use lo < hi + hi=mid. For "maximum": use lo = mid + mid = lo+(hi-lo+1)/2 (round up) to avoid infinite loop.

Prefix Sum

O(n) build · O(1) query
📐

Range Sum Query

Pre-compute → any range sum in O(1)
O(1) query
Use When
  • Multiple range sum queries on a static array
  • Need sum of any subarray after O(n) build
  • "Product of array except self" — prefix/suffix products
arr = [ 2, 4, 3, 7, 1, 5] prefix = [0, 2, 6, 9, 16, 17, 22] ↑ sentinel 0 at index 0 sum(l=1, r=4) = prefix[5] - prefix[1] = 17 - 2 = 15
Java Template
int[] prefix = new int[n + 1]; // size n+1; prefix[0]=0 sentinel for (int i = 0; i < n; i++) prefix[i + 1] = prefix[i] + arr[i]; // Query sum of arr[l..r] inclusive: int rangeSum = prefix[r + 1] - prefix[l];
⚠Allocate prefix[n+1] with sentinel 0 at index 0. Without it the formula changes and you get off-by-one bugs on every query.

Prefix Sum + HashMap

Count subarrays with exact sum k
O(n) / O(n)
Use When
  • Count subarrays with sum exactly equal to k
  • Subarrays divisible by k (use modulo)
  • Equal 0s and 1s — convert 0→-1, find sum=0 subarrays
arr=[1,2,3,-2,3] k=3 running sums: 0→1→3→6→4→7 At i=2: runSum=6, need 6-3=3 in map → found! → subarray [3] At i=4: runSum=7, need 7-3=4 in map → found! → subarray [3] Insight: sum(l,r) = runSum[r] - runSum[l-1] = k ⟹ look for runSum[l-1] = runSum[r] - k
Java Template
Map<Integer,Integer> freq = new HashMap<>(); freq.put(0, 1); // sentinel: empty prefix counts int runSum = 0, count = 0; for (int x : arr) { runSum += x; count += freq.getOrDefault(runSum - k, 0); freq.merge(runSum, 1, Integer::sum); }
⚠Seed the map with put(0,1) before the loop — this handles subarrays starting at index 0 where the whole prefix equals k.
LC 560 · Subarray Sum = K LC 974 · Subarray Div by K LC 525 · Contiguous Array

O(1) avg lookup
🔑

Complement / Two Sum

Store seen values; look up complement each step
O(n) / O(n)
Use When
  • Find a pair summing to target (unsorted)
  • Check if element's complement has been seen
  • Track index of first occurrence of a value
nums=[2,7,11,15] target=9 i=0: need 9-2=7 map={} → not found, store {2:0} i=1: need 9-7=2 map={2:0} → FOUND return [0,1]
Java Template
Map<Integer,Integer> seen = new HashMap<>(); for (int i = 0; i < nums.length; i++) { int complement = target - nums[i]; if (seen.containsKey(complement)) return new int[]{ seen.get(complement), i }; seen.put(nums[i], i); // store AFTER checking }
⚠Store the value after checking — otherwise a single element might match itself (e.g., target=6, nums=[3,…] would falsely match index 0 with itself).

Sort or count chars as a canonical key
O(n·m·log m)

"eat","tea","tan","ate","nat","bat" Sorted key → group: sort("eat")="aet" → [eat,tea,ate] sort("tan")="ant" → [tan,nat] sort("bat")="abt" → [bat]

Map<String,List<String>> map = new HashMap<>(); for (String w : words) { char[] ch = w.toCharArray(); Arrays.sort(ch); String key = new String(ch); map.computeIfAbsent(key, x -> new ArrayList<>()).add(w); }

BFS — Breadth-First Search

O(V+E)
🗺️

Shortest Path / Level-Order

Level by level — guarantees shortest unweighted path
O(V+E) / O(V)
Use When
  • Shortest path in an unweighted graph or grid
  • Minimum steps/transformations to reach target
  • Level-order traversal of a tree
Grid BFS — S to E: [S . . #] [# # . #] BFS: explore nearest first [. . . E] Level 0: [S] Level 1: [→, ↓ of S] ← first reach = shortest path!
Java Template
int[][] DIRS = {{0,1},{0,-1},{1,0},{-1,0}}; Queue<int[]> q = new LinkedList<>(); boolean[][] vis = new boolean[rows][cols]; q.add(new int[]{startR,startC}); vis[startR][startC]=true; int steps = 0; while (!q.isEmpty()) { int sz = q.size(); // one full level for (int i = 0; i < sz; i++) { int[] cur = q.poll(); if (isGoal(cur)) return steps; for (int[] d : DIRS) { int nr=cur[0]+d[0], nc=cur[1]+d[1]; if (inBounds(nr,nc) && !vis[nr][nc]) { vis[nr][nc]=true; q.add(new int[]{nr,nc}); } } } steps++; }
⚠Mark nodes as visited when enqueued (not dequeued) — otherwise the same node gets enqueued many times → TLE.

DFS / Backtracking

O(2^n) or O(n!)
🔙

Backtracking Template

Choose → Explore → Undo
O(2^n) or O(n!)
Use When
  • Generate all subsets / permutations / combinations
  • Find all valid configurations — N-Queens, Sudoku
  • Path in a maze or word grid
Subsets of [1,2,3]: [ ] / \ [1] [ ] / \ / \ [1,2][1][2][ ] / [1,2,3] Pattern: at each position → include or skip
Subsets Template
void backtrack(int start, List<Integer> path) { result.add(new ArrayList<>(path)); // save snapshot! for (int i = start; i < nums.length; i++) { path.add(nums[i]); // CHOOSE backtrack(i + 1, path); // EXPLORE path.remove(path.size() - 1); // UNDO } }
⚠Always add a copy of path to result: new ArrayList<>(path) — not the reference. The original list is mutated during backtracking and will be empty by the end.

DFS on Graph / Grid

Explore deep; mark visited to avoid cycles
O(rows×cols)
Use When
  • Count / mark connected components in a grid
  • Flood fill or find all reachable cells
  • No need for shortest path — just reachability
Grid (1=land, 0=water): [1 1 0] [1 0 0] DFS from (0,0): visits (0,0)→(0,1)→(1,0) [0 0 1] Island 1={3 cells} Island 2={(2,2)}
Java Template
int[][] DIRS = {{0,1},{0,-1},{1,0},{-1,0}}; void dfs(int r, int c) { if (r < 0 || r >= rows || c < 0 || c >= cols) return; if (grid[r][c] != '1') return; grid[r][c] = '0'; // mark visited in-place for (int[] d : DIRS) dfs(r+d[0], c+d[1]); }
⚠Mark cells visited immediately before recursing. Modifying in-place ('1'→'0') saves a separate visited array but mutates input — use boolean[][] if that's unacceptable.

Trees

O(n)
🔍

Tree Traversals

4 orders — each solves a different class of problems
O(n) / O(h)
Use When
  • In-order of BST → sorted output (kth smallest)
  • Pre-order → serialize / clone tree
  • Post-order → bottom-up: height, diameter, path sum
4 / \ 2 6 / \ / \ 1 3 5 7 In-order L→N→R: 1 2 3 4 5 6 7 ← sorted! Pre-order N→L→R: 4 2 1 3 6 5 7 ← serialize Post-order L→R→N: 1 3 2 5 7 6 4 ← delete/aggregate Level-order: 4 2 6 1 3 5 7 ← BFS
Traversal Skeleton
void dfs(TreeNode node) { if (node == null) return; // visit(node); ← PRE-ORDER (serialize) dfs(node.left); // visit(node); ← IN-ORDER (BST → sorted) dfs(node.right); // visit(node); ← POST-ORDER (aggregate children) }
⚠In-order of a BST gives sorted values — the key insight for "kth smallest" BST problems. For level-order, loop over q.size() at start of each iteration to separate levels.

📐

Return-Value Pattern

Post-order: ask children → combine → return to parent
O(n) / O(h)
Use When
  • Answer involves both subtrees — height, diameter
  • Parent needs a different value than what you record as answer
  • Max path sum, longest path through any node
Max Path Sum: -10 / \ 9 20 / \ 15 7 At node 20: left=15, right=7 → global ans = max(ans, 15+20+7=42) → return to parent: 20+max(15,7)=35
Java Template
int ans = Integer.MIN_VALUE; // global int dfs(TreeNode node) { if (node == null) return 0; int left = Math.max(0, dfs(node.left)); // discard negatives int right = Math.max(0, dfs(node.right)); ans = Math.max(ans, left + right + node.val); // update global return node.val + Math.max(left, right); // tell parent }
⚠Use Math.max(0, dfs(child)) to discard negative branches. The return value tells parent the best single-path gain; the global var captures the answer that may split.

🗺️

Dijkstra's Algorithm

Min-heap + greedy for weighted shortest paths
O((V+E) log V)
Use When
  • Shortest path in weighted graph (non-negative weights)
  • "Minimum cost to reach all nodes from source"
  • With k-stop limit → use Bellman-Ford instead
A─2─B─1─D └─4─C─3─┘ From A: dist=[A:0, B:∞, C:∞, D:∞] PQ=[(0,A)] Pop(0,A)→ B=2, C=4 PQ=[(2,B),(4,C)] Pop(2,B)→ D=3 PQ=[(3,D),(4,C)] Pop(3,D)→ done dist[D]=3
Java Template
int[] dist = new int[n]; Arrays.fill(dist, Integer.MAX_VALUE); dist[src] = 0; PriorityQueue<int[]> pq = new PriorityQueue<>(Comparator.comparingInt(a->a[0])); pq.offer(new int[]{0, src}); while (!pq.isEmpty()) { int[] cur = pq.poll(); if (cur[0] > dist[cur[1]]) continue; // stale entry! for (int[] nb : graph.get(cur[1])) if (dist[cur[1]] + nb[1] < dist[nb[0]]) { dist[nb[0]] = dist[cur[1]] + nb[1]; pq.offer(new int[]{dist[nb[0]], nb[0]}); } }
⚠Skip stale entries: if (cur[0] > dist[cur[1]]) continue — the PQ may hold outdated (higher-cost) entries for nodes already relaxed.

Topological Sort (Kahn's BFS)

Process in-degree=0 nodes first; cycle if leftover
O(V+E)
Use When
  • Tasks with prerequisites / dependencies
  • Check if a directed graph has a cycle (DAG check)
  • Find a valid ordering of courses / tasks
Prereqs: [[1,0],[2,0],[3,1],[3,2]] In-degree: {0:0, 1:1, 2:1, 3:2} Queue=[0] (in-degree=0) Pop 0 → reduce 1→0, 2→0 → Queue=[1,2] Pop 1 → reduce 3→1 → Queue=[2] Pop 2 → reduce 3→0 → Queue=[3] Pop 3 → Order: [0,1,2,3] ✓ |order|≠n → cycle!
Java Template
int[] indegree = new int[n]; for (int[] e : edges) indegree[e[0]]++; Queue<Integer> q = new LinkedList<>(); for (int i=0;i<n;i++) if (indegree[i]==0) q.add(i); List<Integer> order = new ArrayList<>(); while (!q.isEmpty()) { int node = q.poll(); order.add(node); for (int nb : graph.get(node)) if (--indegree[nb] == 0) q.add(nb); } return order.size() == n; // false = cycle exists
⚠If order.size() != n, there is a cycle — some nodes never had in-degree 0. This is Kahn's built-in cycle detection.

Union-Find (DSU)

≈ O(α(n))
🔗

DSU — Path Compression + Rank

Merge components; detect cycles; build MST (Kruskal)
O(α(n)) per op
Use When
  • Dynamically connect components and check connectivity
  • Detect if adding an edge creates a cycle
  • Build a minimum spanning tree (Kruskal's algorithm)
parent=[0,1,2,3,4] union(0,1): parent[1]=0 union(2,3): parent[3]=2 union(0,2): parent[2]=0 → {0,1,2,3} and {4} find(3): 3→2→0 path compress: parent[3]=0 directly union(x,y) returns false → already connected = cycle!
Java Template
int[] parent, rank; void init(int n) { parent=new int[n]; rank=new int[n]; for(int i=0;i<n;i++) parent[i]=i; } int find(int x) { if(parent[x]!=x) parent[x]=find(parent[x]); // path compress return parent[x]; } boolean union(int x, int y) { int px=find(x), py=find(y); if(px==py) return false; // same component → cycle! if(rank[px]<rank[py]) { int t=px;px=py;py=t; } parent[py]=px; if(rank[px]==rank[py]) rank[px]++; return true; }
⚠union() returning false means already connected → cycle detected. In Kruskal's MST, skip the edge when union returns false.

1-D DP

dp[i] depends on a few previous states
O(n) / O(1) or O(n)
Use When
  • Count ways to reach state i — climbing stairs, coin change
  • Max/min value from a sequence — house robber
  • Longest increasing subsequence: dp[i]=max dp[j]+1
House Robber: dp[i] = max(dp[i-1], dp[i-2]+nums[i]) nums = [2, 7, 9, 3, 1] dp = [2, 7,11,10,12] ans=12 Coin Change: min coins for amount=11, coins=[1,5,6] dp[0]=0, dp[5]=1, dp[6]=1 dp[11] = min(dp[10]+1, dp[6]+1, dp[5]+1) = 2 (5+6)
House Robber (space-optimized)
int prev2 = 0, prev1 = 0; for (int num : nums) { int curr = Math.max(prev1, prev2 + num); prev2 = prev1; prev1 = curr; } return prev1;
⚠Define base cases carefully. For coin change, initialize dp[0]=0 and all others to amount+1 (infinity) — invalid states must not propagate forward.

2-D DP

dp[i][j] — two sequences or a grid
O(m×n)
Use When
  • Two sequences: LCS, edit distance, LPS
  • Grid paths: unique paths, min path sum
  • 0/1 Knapsack: items × capacity table
LCS("ace", "abcd"): "" a b c d "" [ 0 0 0 0 0 ] a [ 0 1 1 1 1 ] c [ 0 1 1 2 2 ] e [ 0 1 1 2 2 ] LCS = 2 ("ac")
LCS Template
int[][] dp = new int[m+1][n+1]; // 1-indexed! for (int i=1; i<=m; i++) for (int j=1; j<=n; j++) if (s1.charAt(i-1) == s2.charAt(j-1)) dp[i][j] = dp[i-1][j-1] + 1; else dp[i][j] = Math.max(dp[i-1][j], dp[i][j-1]);
⚠Use 1-indexed DP (size m+1 × n+1) so dp[0][j] and dp[i][0] are base cases for the empty string — eliminates most off-by-one errors.

Jump Game / Reach

Track farthest reachable index; never look back
O(n) / O(1)
Use When
  • Can you reach the end with given jump lengths?

QuickSelect — Kth Element

Partition like QuickSort; recurse only one side
O(n) avg / O(n²) worst
Use When
  • Find kth largest without full sort — O(n) avg
  • One-time query (streaming → use Heap instead)
