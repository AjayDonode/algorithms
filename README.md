# algorithms

This is a web based application for learning Data Structures and Algorithms.

## Getting Started

### Prerequisites

- Node.js (v16+)
- Python (v3.10+)
- Java (JDK 17+)

### Installation

```bash
# Install Next.js app dependencies
cd portal
npm install

# Start the development server
npm run dev
```

The application will be available at `http://localhost:3000`.

## Using the IDE

The IDE supports multiple languages. To use a specific language, ensure the corresponding runtime is installed on your system.

- **Java**: Install JDK 17+
- **Python**: Install Python 3.10+
- **JavaScript**: No installation required

The system will automatically detect installed runtimes and configure them for the IDE.
